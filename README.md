# DeepMine — Telegram Mini App Idle Miner

MVP Telegram Mini App with React/Vite frontend and Express backend.
The prototype includes mining, upgrades, workers, depth progression, offline earnings,
daily reward, missions, achievements, leaderboard placeholder, and Telegram WebApp integration.

## Run
```bash
npm install
npm run dev
```

Frontend: http://localhost:5173
Backend: http://localhost:3000

For production, set `VITE_API_URL` to the backend URL and configure your Telegram bot's
Mini App URL through BotFather. PostgreSQL can be added using the included server structure.
